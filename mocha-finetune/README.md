# mocha-finetune

Fine-tuning environment to make a local LLM sound like **Mocha** — a tsundere AI assistant.
Three approaches, one config file, shared data pipeline.

## Hardware Requirements
- GPU: NVIDIA RTX PRO 6000 Blackwell (96GB VRAM) — GPU 0
- CUDA: 12.8
- PyTorch: nightly (for Blackwell support)
- OS: WSL2 Ubuntu

```bash
pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cu128
pip install unsloth trl datasets transformers anthropic pyyaml requests
```

## Quick Start

```bash
cd ~/ProjectParrot/mocha-finetune

# 1. Prepare datasets (run once)
python3 scripts/prepare_data.py

# 2a. SFT training (fastest, start here)
python3 01-sft/train.py

# 2b. DPO training (needs rejected responses first)
python3 02-dpo/generate_rejected.py
python3 02-dpo/train.py

# 2c. QLoRA 70B (best ceiling, requires HuggingFace download of LLaMA 70B)
python3 03-qlora-70b/train.py

# 3. Evaluate any approach
python3 01-sft/eval.py
```

## Changing Models
Edit `config.yaml`:
```yaml
models:
  sft_base: "Qwen/Qwen2.5-32B-Instruct"   # change to any HuggingFace model
  qlora_base: "meta-llama/Meta-Llama-3.1-70B-Instruct"
```

## Adding Judge Models
Edit `config.yaml`:
```yaml
judge_models:
  - provider: "anthropic"
    model: "claude-haiku-4-5"
    api_key_env: "ANTHROPIC_API_KEY"
  - provider: "openai"        # uncomment to add
    model: "gpt-4o-mini"
    api_key_env: "OPENAI_API_KEY"
  - provider: "ollama"        # free local judge
    model: "qwen2.5:32b"
    base_url: "http://host.docker.internal:11434"
```

## Training Order (recommended)
1. **01-sft** first — fastest to converge, establishes baseline personality
2. **02-dpo** next — uses SFT output as base if you set `dpo_base` to the SFT adapter path
3. **03-qlora-70b** — best quality ceiling, needs LLaMA 70B downloaded separately

## Directory Structure
```
mocha-finetune/
├── config.yaml           ← EDIT THIS to change models/hyperparams/judges
├── data/
│   ├── raw/mocha_raw.json    ← source conversation data
│   ├── sft/train.json        ← generated by prepare_data.py
│   ├── dpo/pairs_*.json      ← generated by prepare_data.py + generate_rejected.py
│   └── eval/eval.json        ← held-out eval set
├── scripts/
│   ├── prepare_data.py   ← run first
│   └── run_judge.py      ← LLM scoring
├── 01-sft/               ← supervised fine-tuning
├── 02-dpo/               ← preference learning
├── 03-qlora-70b/         ← 70B quantized training
└── outputs/              ← trained adapters + eval results
```

## After Training: Using the Adapter
Fine-tuned adapters are LoRA — they need to be merged with the base model to use with Ollama:

```python
# Merge and export to GGUF (Ollama format)
from unsloth import FastLanguageModel
model, tokenizer = FastLanguageModel.from_pretrained("outputs/sft/adapter")
model.save_pretrained_gguf("outputs/sft/mocha-q8", tokenizer, quantization_method="q8_0")
# Then: ollama create mocha-sft -f outputs/sft/mocha-q8/Modelfile
```
